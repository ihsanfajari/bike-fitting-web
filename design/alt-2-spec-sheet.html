EXECUTION NOTE

Karakter Spec Sheet bekerja paling kuat ketika listing memang punya spec lengkap. Untuk seller yang ogah isi 20 field, ini bisa terasa intimidating. Mitigation: progressive disclosure di form listing — minimum required fields dulu (5-6), spec detail opsional. Display tetap konsisten: kalau spec tidak diisi → tampil — NOT SPECIFIED — dengan dignity, bukan kosong.
